# Detection to Control Matrix

| Detection | Data Source | Tool | CISSP Domain |
|---|---|---|---|
| Failed SSH Logins | Linux Auth Logs | Elastic SIEM | Domain 5, Domain 7 |
| Windows Failed Logins | Windows Security Logs | Elastic SIEM | Domain 5, Domain 7 |

## Purpose

This matrix demonstrates how security monitoring controls implemented in the SIEM lab map to CISSP domains and operational security objectives.
